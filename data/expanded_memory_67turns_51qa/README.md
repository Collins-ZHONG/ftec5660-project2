# Expanded Memory Set: All Local Questions

This derived LoCoMo file uses sample `conv-26` and retains sessions D2, D17, and D18 (67 conversation turns total). It includes the 51 original QA items whose evidence is entirely within those sessions.

The question distribution is category 1: 3, category 2: 5, category 3: 1, category 4: 26, and category 5: 16. Results from this set should be reported separately from the 16-question fixed-question experiment because the evaluated question set differs.

The source `data/locomo10.json` is unchanged. Session date fields and matching event summaries, observations, and session summaries are retained only for D2, D17, and D18. This is a selected subset, not the full LoCoMo benchmark.
