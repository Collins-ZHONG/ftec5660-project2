# Expanded Memory Set: Fixed Questions

This derived LoCoMo file uses sample `conv-26` and retains sessions D2, D17, and D18 (67 conversation turns total). It keeps the original 16 QA items whose evidence is entirely in D2, so the small and expanded memory conditions use the same questions.

The added sessions provide later adoption-related memories and unrelated family/travel events. This set is intended to test whether a larger memory store changes retrieval for the same questions. It is a selected subset, not the full LoCoMo benchmark.

The source `data/locomo10.json` is unchanged. Session date fields and matching event summaries, observations, and session summaries are retained only for D2, D17, and D18.
