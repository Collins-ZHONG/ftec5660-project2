# A-MEM LoCoMo 复现：阶段性结论

## 复现目标

本实验复现 A-MEM 在 LoCoMo 对话记忆问答任务中的一小部分行为，并做一个可测量的参数修改：比较默认检索数量 `retrieve_k=10` 与 `retrieve_k=5`。实验分为两种记忆长度：初始 pilot 保留 conv-26 的 D2（17 轮）；扩展实验保留 D2、D17、D18（67 轮）。两种长度均使用相同的 16 道 D2 原始问题。

这是一项**小规模子集复现与参数对照**，目标是观察实现能否运行、改变检索数量后指标如何变化；不以复现论文全量分数为目标。

## 与原实验一致的部分

- 使用公开的 A-MEM 仓库代码和 LoCoMo 对话记忆问答数据，任务仍是先从对话构建记忆，再根据问题检索记忆并生成答案。
- 使用仓库的 robust 评测入口和其记忆、检索、回答流程；`k=10` 是脚本默认基线，`k=5` 是本实验唯一计划内的检索参数修改。
- 在同一记忆长度的 k=10/k=5 对照中，固定数据、16 道题、DeepSeek 后端、embedding 模型、提示词和评估脚本。每组使用相同 seed 配对运行，重复五组。
- 扩展实验没有另写问题或改答案，而是保留原 D2 问题，仅增加同一对话中 D17、D18 的背景轮次，因此可以观察更大的记忆库下原问题的表现。

## 与论文实验的主要差异

| 方面 | 论文/标准实验目标 | 本次复现 | 对解释的影响 |
|---|---|---|---|
| 数据规模 | 在 LoCoMo 基准的多个对话及其 QA 上评估 | 只用 conv-26 的一个派生子集，16 道题 | 单一对话的主题、措辞和样本构成可能主导结果，不能外推到完整基准 |
| 问题覆盖 | 基准提供多种问题类别 | 本子集类别分布为 1、2、4、5 类各 1、2、8、5 题；没有类别 3 | 类别级统计的样本数过少，不适合宣称类别效果 |
| 记忆长度 | 论文基准实验按其完整数据设置运行 | pilot 为 D2 的 17 轮；扩展条件为 D2+D17+D18 的 67 轮 | 扩展条件只代表一个经过筛选的较长对话，不等同于完整长对话基准 |
| LLM 后端 | 论文使用其指定模型与服务配置 | DeepSeek API，`deepseek-chat` | 模型、提示遵循和生成随机性均可能造成分数差异，数值不能与论文直接对比 |
| 重复与随机性 | 论文报告其自身设定下的结果 | 每个条件五次；seed 控制类别 5 的选项顺序，不控制 LLM 输出随机性 | 均值和标准差描述本次运行波动，不是独立数据样本上的置信区间 |
| 记忆缓存 | 论文完整实验流程与本次环境不完全相同 | 每个数据长度各生成一次记忆缓存，同长度的 k=10/k=5 及重复运行共享该缓存 | 控制了 k 对照中的记忆构建差异，但没有测量重复构建记忆的波动 |
| 评测实现 | 论文使用其报告的模型、数据和评价配置 | 使用克隆仓库中的 robust 脚本、DeepSeek 和当前依赖环境 | 结果适合做同一脚本内的相对比较，不应称为论文分数复现 |

以上差异中，影响最大的是**只测一个对话的 16 道题**和**用 DeepSeek 代替论文的模型环境**。因此本实验能说明本地复现代码在所选条件下的行为，不能据此判断 A-MEM 在完整 LoCoMo 上达到或超过论文报告表现。

## 扩展数据前：17 轮 pilot 的简单结论

扩展数据前的 pilot 只使用 conv-26 的 D2，共 17 轮、16 道题；k=10 和 k=5 各运行五次。五次均没有记录 LLM 调用失败，所有运行都使用同一份 pilot 记忆缓存。

| 指标（五次均值 ± 标准差） | k=10 | k=5 |
|---|---:|---:|
| Exact Match | 0.375 ± 0.000 | 0.400 ± 0.056 |
| Token F1 | 0.594 ± 0.016 | 0.561 ± 0.051 |
| BERT F1 | 0.943 ± 0.002 | 0.939 ± 0.007 |
| SBERT 相似度 | 0.727 ± 0.003 | 0.699 ± 0.048 |
| 对抗题正确率 | 0.60 ± 0.00 | 0.68 ± 0.18 |

**简单结论：** pilot 中 k=10 的 Token F1、BERT F1 和 SBERT 相似度均值较高，且波动较小；k=5 的 Exact Match 均值仅略高，对抗题均值也略高，但两者都受单次较好结果影响。k=10 在总体答案匹配上呈现较稳定的优势迹象，尚不足以证明其普遍优于 k=5。

## 检索数量对照：67 轮扩展数据

五次运行的总体均值如下：

| 指标 | k=10 | k=5 | 描述 |
|---|---:|---:|---|
| Exact Match | 0.488 | 0.463 | k=10 高 0.025 |
| Token F1 | 0.620 | 0.604 | k=10 高 0.016；配对五组中四组更高 |
| BERT F1 | 0.946 | 0.941 | k=10 高 0.005 |
| SBERT 相似度 | 0.736 | 0.718 | k=10 高 0.018 |
| 对抗题正确率 | 0.84 | 0.92 | k=5 高 0.08 |

在这个子集和固定缓存下，k=10 的总体答案匹配指标略高，k=5 的对抗题正确率略高。差距有限，且各次运行有波动；结论应限于“本子集上 k=10 的总体匹配略占优”，不能说 k=10 普遍更好。

## 记忆长度对照：17 轮 pilot 与 67 轮扩展

两种数据长度使用相同的 16 道问题。五次运行均值的描述性对比如下：

| 检索设置 | 指标 | 17 轮 pilot | 67 轮扩展 |
|---|---|---:|---:|
| k=10 | Exact Match | 0.375 | 0.488 |
| k=10 | Token F1 | 0.594 | 0.620 |
| k=10 | BERT F1 | 0.943 | 0.946 |
| k=10 | SBERT 相似度 | 0.727 | 0.736 |
| k=5 | Exact Match | 0.400 | 0.463 |
| k=5 | Token F1 | 0.561 | 0.604 |
| k=5 | BERT F1 | 0.939 | 0.941 |
| k=5 | SBERT 相似度 | 0.699 | 0.718 |

扩展条件的这些均值都较高，**没有观察到增加背景轮次后总体指标下降**。这与“记忆变多必然使当前问题更难”的简单预期不符；增加的轮次可能补充了有用上下文，也可能只是模型生成波动或记忆构建差异造成的结果。

这不是严格的文本量因果检验：17 轮和 67 轮条件各自独立生成了记忆缓存，评测也只覆盖一个对话和 16 道题。故只能报告为**观察到扩展组均值较高**，不能说“增加文本导致性能提高”，也不能用它证明遗忘假设成立或不成立。

## 对机制和理论假设的解释

代码中的 `retrieve_k` 控制向量检索返回的种子记忆数；每条种子还会扩展相连的邻居记忆，之后 LLM 再从候选上下文中筛选相关片段。k=10 可能因候选更多而更容易包含答案线索，尤其当线索分散在多条记忆中。相反，额外记忆也可能增加无关上下文。因此，结果**弱支持“较大的检索候选数可能略有利于总体答案匹配”这一局部工作假设**，但没有记录检索命中率或候选上下文的相关性，不能确认这就是 k=10 占优的原因。

本实验**没有验证 A-MEM 的核心理论主张**，例如 Zettelkasten 式链接、动态记忆组织或记忆演化是否优于其他记忆方法。实验没有关闭链接、替换记忆算法或与无链接基线比较；改变的只是检索数量。也没有直接证明模型“遗忘”了旧信息。

## 为什么暂不按论文类别讨论

当前子集类别规模太小，分类别数字极易被个别回答左右：类别 1 只有 1 题，一题就改变 100 个百分点；类别 2 只有 2 题，且两种 k 的五次运行 F1 始终为 0；类别 5 只有 5 题，一题会改变 20 个百分点，k=10 的五次正确率就在 0.6、0.8、1.0 间变化。整体也有明显波动：k=10 的 Token F1 五次范围为 0.472–0.691，Exact Match 为 0.375–0.563。五组运行不足以把这些极端值解释为稳定的类别差异，故正文只报告总体指标；类别数字至多可作为附录探索性结果。

## 运行异常及复现记录

- 第一次扩展 k=5 曾因 DeepSeek API 请求超时退出，没有结果文件；随后单独重跑成功，加载了相同的 67 条缓存。超时运行未纳入五组结果。
- Hugging Face 检查句向量模型配置时出现网络重试信息；本地权重已加载，最终评测成功。此信息与 DeepSeek API 超时是不同问题。
- 结果文件为本目录下 `expanded_k{5,10}_rep{1..5}.json`；运行日志在仓库 `logs/` 目录。17 轮 pilot 的结果文件为仓库根目录下 `pilot_k{5,10}[_repN].json`。

## 可用于报告的简短结论

本项目在 A-MEM 公开实现上完成了一个 LoCoMo 子集复现，并比较了 `retrieve_k=10` 与 `retrieve_k=5`。对单一对话的 16 道固定问题重复五次后，67 轮扩展条件下 k=10 的总体匹配均值略高，k=5 的对抗题正确率略高；扩展记忆条件的总体均值也高于 17 轮 pilot。由于数据子集小、使用 DeepSeek 而非论文模型、记忆缓存只构建一次，这些结果是实现内的初步趋势，不能视为论文全量数值复现或对 A-MEM 理论的验证。
